# Deep Learning with PyTorch

This repository is a collection of practice deep learning tests in jupyter notebook and Python with machine learning libraries and tests performed alongside PyTorch.

## Installation

To install the required dependencies, please run the following command:

```bash
pip install -r requirements.txt
```

Make sure you have Python 3.6 or higher installed on your system.

## Usage

To run the Jupyter notebooks, use the following command:

```bash
jupyter notebook
```

This will open the Jupyter Notebook interface in your web browser, where you can navigate to the notebooks and run them.

## PyTorch

This repository uses PyTorch as the primary deep learning framework. You can find more information about PyTorch and its installation instructions at the [official PyTorch website](https://pytorch.org/).
